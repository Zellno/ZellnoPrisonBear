# Testing

Version 0.3.0 was tested on DayZ 1.29 with:

- successful server and client loading;
- spawning through VPPAdminTools;
- controlled static spawning;
- three simultaneous instances;
- death and skinning;
- server restart and respawn;
- signature validation;
- Linux server and Linux client.

Weapon-specific balance is not guaranteed on other servers because
ammunition damage can be changed by other mods.

Private production coordinates and complete server profiles are deliberately
excluded from this repository.
